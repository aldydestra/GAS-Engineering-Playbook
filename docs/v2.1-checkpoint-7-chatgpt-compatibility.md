# GAS Engineering v2.1 — Checkpoint 7: ChatGPT Reference Compatibility

**Tanggal:** 6 November 2026 | **Release:** `Unreleased` | **Stable:** `v2.0.0` (frozen)

## Tujuan

Memungkinkan materi GAS Engineering Playbook digunakan **langsung di percakapan ChatGPT** atau sebagai referensi ChatGPT Project, tanpa mengharuskan pengguna memasang plugin, agent skill, atau toolchain Python. Ini *reference compatibility*, **bukan** registrasi skill otomatis dan **bukan** akses ke akun Google.

Penggunaan ChatGPT berbeda dari host Agent Skills: mengunggah `.txt` menyediakan materi rujukan yang dapat dibaca model, tetapi tidak menjamin semua dokumen masuk ke konteks setiap jawaban. Untuk host yang mendukung instalasi skill, format `gas-engineering.skill` tetap tersedia di arsip stabil v2.0.0 dan pada build development (diabaikan Git).

## Artefak dan kegunaannya

| Artefak | Ukuran relatif | Saat digunakan |
|---|---|---|
| `GAS_CHATGPT_CONTEXT.txt` | Ringkas | **Unggah ini terlebih dahulu** ke chat atau Project, lalu tanyakan pekerjaan GAS |
| `CHATGPT_PROJECT_INSTRUCTIONS.txt` | Sangat ringkas | Tempel isinya di **Project Instructions** agar pemilihan 6 task-family konsisten |
| `GAS_CHATGPT_SPECIALISTS.txt` | Besar; 16 skill penuh | Unggah ketika membutuhkan rujukan mendalam dari beberapa spesialis; model bisa membatasi/retrieve sebagian |
| `GAS_CHATGPT_RELIABLE_JOBS.txt` | Sedang; 3 starter `.gs` | Review, adaptasi, debugging checkpoint/resume/trigger/reconciliation |
| `CHATGPT_STAGING_REVIEW_TEMPLATE.txt` | Sangat ringkas | Templat review JSON staging yang sudah disanitasi |
| `MANIFEST.json` | Metadata | SHA-256 setiap sumber spesialis dan setiap file handoff |
| `gas-chatgpt-context-v2.1-cp7.zip` | Arsip portabel | **Ekstrak dulu**, lalu unggah `.txt` sesuai kebutuhan; jangan mengandalkan ZIP langsung terbaca UI |

**Cara membuat:**

```bash
python tools/build_chatgpt_context.py
python tools/build_chatgpt_context.py --verify
PYTHONPATH=tools python -m unittest tools.test_chatgpt_context -v
```

Hasil disimpan ke `dist/chatgpt-v2.1-cp7/`; `dist/` sengaja tidak masuk git (mencegah long path Windows), tetapi builder dapat meregenerasi byte-identical dari source `skills/`, `packaging/`, `examples/`, `chatgpt/`. Jika source berubah, jalankan builder kembali.

## Peta penggunaan

1. **Chat biasa:** unggah `GAS_CHATGPT_CONTEXT.txt`, berikan kebutuhan serta file `.gs`/log relevan (tanpa kredensial). Jika butuh kedalaman spesialis, tambahkan `GAS_CHATGPT_SPECIALISTS.txt`.
2. **ChatGPT Project:** tambahkan file `.txt` ke sumber Project. Tempel `CHATGPT_PROJECT_INSTRUCTIONS.txt` ke Project Instructions. Fitur dan limit unggahan mengikuti akun/klien/workspace.
3. **Review proyek GAS:** minta analisis, rekomendasi, dan patch kode. Konfirmasi apakah pengujian sungguhan dijalankan; tidak boleh mengklaim otomatis telah mengeksekusi Apps Script atau memperoleh izin OAuth.
4. **Review staging Reliable Jobs:** gunakan `CHATGPT_STAGING_REVIEW_TEMPLATE.txt` dan *sanitized evidence*. Validasi struktur JSON tidak membuktikan hasil Google Executions; tinjau event trigger riil terpisah.

## Kontrak dan batasan

- **16/16** spesialis tercakup dalam file referensi panjang byte-for-byte dari `SKILL.md`; ringkasan memuat nama/versi/deskripsi seluruh spesialis dan **6/6** task-family.
- **3/3** starter `.gs` dibundel byte-for-byte dari `examples/gas-reliable-jobs-v2.1` dengan salinan source skill 01 harus identik.
- Manifest mengikat sumber dengan SHA-256; builder deterministik dan verifier menolak file output yang berubah.
- **Tidak mengubah** `releases/v2.0.0/gas-engineering.skill`, kebijakan release, atau versi internal skill selama `Unreleased`.
- Tidak ada bukti pemanggilan otomatis/activation skill di ChatGPT; pengujian ini mengukur kualitas *reference packaging* saja.
- Materi panjang bisa tidak dibaca penuh dalam satu interaksi. Mulai dari konteks ringkas, muat file khusus sesuai tugas.

## Quality gates

Unit: `tools/test_chatgpt_context.py`, ditambah regression GAS yang sudah ada. CI membangun dan memverifikasi context pack serta mengeksekusi unit test. Live ChatGPT attachment behavior dan live GAS staging **belum diujikan secara menyeluruh**; tidak mengklaim kompatibilitas universal untuk semua klien/paket.

## Versi skill

Tidak ada kenaikan versi 16 spesialis pada CP7 karena tujuan checkpoint adalah **lapisan kompatibilitas ChatGPT dan distribusi referensi**, bukan perubahan aturan runtime. Nomor versi skill akan diperbarui pada rilis minor stabil berikutnya bila kontennya benar-benar berubah.
