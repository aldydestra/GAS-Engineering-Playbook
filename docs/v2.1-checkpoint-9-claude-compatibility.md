# Claude Compatibility — Checkpoint 9 (10 November 2026)

**Status:** v2.1.0 Unreleased · **Stable unchanged:** v2.0.0 · **Host runtime tests:** NOT_RUN.

Checkpoint 9 menambahkan dua format berbeda dari satu sumber pengetahuan GAS yang sama. Jangan menganggap ZIP konteks yang dilampirkan di chat sebagai instalasi skill.

## 1. Claude Chat / Projects (referensi, bukan aktivasi)

1. Build: `python tools/build_claude_context.py` (setelah build one-install `python tools/gas_skill_packager.py && python tools/build_gas_v2.py`).
2. Buka `dist/claude-v2.1-cp9/CLAUDE_GAS_CONTEXT.txt` lalu **unggah file `.txt` langsung** ke Claude Chat. Untuk masalah spesifik, tambahkan satu `GAS_FAMILY_*.txt` dan `CLAUDE_GAS_RELIABLE_JOBS.txt` bila dibutuhkan.
3. Dalam Claude Project, taruh referensi pada Knowledge/Files dan salin `CLAUDE_PROJECT_INSTRUCTIONS.txt` ke Project Instructions. Periksa batas ukuran/konteks akun.
4. `gas-claude-context-v2.1-cp9.zip` adalah *paket pengiriman untuk diekstrak*; jangan mengasumsikan ZIP lampiran chat otomatis diekstrak atau dikenali sebagai skill. Ada **10 file datar**: quick context, 6 family references, project instructions, Reliable Jobs source, manifest SHA-256.

## 2. Claude Custom Skills / Claude Code (skill native)

- **Claude.ai Custom Skills**: melalui `Customize → Skills → + Create skill → Upload a skill`, unggah **`gas-claude-skill-v2.1-cp9.zip`**. Ini bukan area lampiran chat. Requires skills and code execution enabled; organisasi dapat membatasi fitur.
- **Claude Code**: ekstrak ZIP sehingga path menjadi `.claude/skills/gas-engineering/SKILL.md` (per proyek) atau `~/.claude/skills/gas-engineering/SKILL.md` (personal). Pertahankan seluruh `references/` pada folder yang sama. Pastikan invokasi/discovery melalui Claude Code, bukan menganggap staging test lokal sebagai aktivasi nyata.
- ZIP skill menggunakan **tepat satu folder root `gas-engineering/`**, frontmatter valid `name: gas-engineering`, deskripsi dibatasi ≤200 karakter khusus Claude; keenam belas spesialis/referensi disalin byte-for-byte dari one-install GAS development build.
- ZIP skill bukan pengganti `releases/v2.0.0/gas-engineering.skill` stabil. Ini adalah **adapter untuk development content Checkpoint 9**; jangan beri tag v2.1.0 stable sebelum quality gate dan staging nyata selesai.

## 3. Scope dan pengujian

- 16 GAS specialists / 6 task-families / 1 front door. Version number 16 specialists tetap sama (content GAS CP1–CP9 masih Unreleased).
- Generator: `tools/build_claude_context.py`; `python tools/build_claude_context.py --verify` menolak file/ZIP yang hilang atau drift.
- Test: `tools/test_claude_context.py` memeriksa frontmatter, layout native, SHA-256, exact skill/source coverage, path safety, determinisme dan tamper.
- Pembedaan evidence: **local packager PASS tidak sama dengan upload/activation Claude.ai PASS**; Google Apps Script staging tetap NOT_RUN.
- Tidak mengirim token, spreadsheet ID, `.clasprc.json`, ataupun log bisnis pengguna dalam artefak.

## 4. GAS staging baru: fixture sintetis sekali buat

Pada `StagingValidation.gs`, fungsi `createReliableJobsSyntheticStagingFixture('CREATE_DISPOSABLE_STAGING_FIXTURE')` menghasilkan **spreadsheet baru** dengan `SOURCE`/`TARGET`, 1.200 baris sintetis dan header `record_id,value`. Ini memerlukan otorisasi Google Sheets dan membuat file baru milik operator. Ia tidak membuka/memodifikasi spreadsheet yang terkonfigurasi atau data produksi.

Pembuatan membutuhkan *exact acknowledgement*, `LockService`, dan menyimpan identitas fixture lebih awal untuk mencegah duplikasi buta setelah kegagalan parsial. Jika `CREATED_NEEDS_POPULATION`, **jangan langsung mengulang**: periksa spreadsheet yang telah tercipta dalam akun operator. `inspectReliableJobsSyntheticStagingFixture()` hanya mengeluarkan status/tanggal/jumlah baris tanpa spreadsheet ID. Fungsi ini **tidak otomatis menjalankan job, tidak membuat Google Apps Script project, dan tidak menghapus file**. Operator masih perlu menyalin ID yang dihasilkan secara lokal ke `GAS_RJ_DEMO_SHEET_ID`, memeriksa preflight, lalu menjalankan probe/job di akun staging.

Perubahan SOURCE setelah job dimulai dilarang. Snapshot per-eksekusi mengurangi drift, tetapi tidak memberikan transactional isolation bila Sheets berubah selama satu pembacaan. Pembacaan dan pengujian simulasi Node bukan bukti performa akun Google.
