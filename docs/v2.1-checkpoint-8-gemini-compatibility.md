# Checkpoint 8 — Gemini Chat, Gems & Gemini CLI Compatibility

**Tanggal:** 9 November 2026 · **State:** `v2.1.0 IN_DEVELOPMENT` (`Unreleased`) · **Stable:** `v2.0.0` tetap dibekukan.

## 1. Ringkasan kompatibilitas

| Target | Cara memakai | Apa yang TIDAK terjadi |
|---|---|---|
| **Gemini Apps (Gemini Chat)** | Unggah `GEMINI_GAS_CONTEXT.txt` dan satu file `GAS_FAMILY_*.txt` untuk permintaan tertentu. Sebagai alternatif unggah ZIP `gas-gemini-context-v2.1-cp8.zip` (persis 10 file) jika opsi ZIP tersedia. | Tidak menginstal `SKILL.md`, tidak memanggil `activate_skill`, tidak memberi akses ke akun GAS atau Workspace. |
| **Gemini Gems** | Buat Gem khusus, tempel teks `GEMINI_GEM_INSTRUCTIONS.txt` di Instructions; tambahkan `GEMINI_GAS_CONTEXT.txt` dan family yang sering digunakan ke Knowledge. | Knowledge adalah bahan rujukan; bukan executor GAS. File yang tersedia dan batas platform dapat berbeda sesuai akun. |
| **Gemini CLI** | Gunakan single-install `gas-engineering.skill` dari hasil development build atau lokasi folder `gas-engineering/SKILL.md` yang ditemukan CLI. | Mengunggah paket referensi ke Gemini Apps tidak memasangnya ke Gemini CLI. Aktivasi CLI mengikuti discovery/consent milik CLI. |

Rujukan Google (diperiksa 9 November 2026):

- Gemini Apps upload: https://support.google.com/gemini/answer/14903178?hl=en — ZIP maksimal 10 file dan 100 MB; batas bergantung akun/fitur.
- Gem custom Knowledge: https://support.google.com/gemini/answer/15235603?hl=en dan https://support.google.com/gemini/answer/15146780?hl=en.
- Gemini CLI skill discovery: https://geminicli.com/docs/cli/skills/ dan https://geminicli.com/docs/cli/tutorials/skills-getting-started/.

## 2. Isi ZIP Gemini (tepat 10 file)

| File | Materi | Rekomendasi |
|---|---|---|
| `GEMINI_GAS_CONTEXT.txt` | Navigasi ringkas, cara kerja, 6 task-family | Unggah lebih dulu di chat |
| `GAS_FAMILY_RUNTIME_AUTOMATION.txt` | GAS Core, Performance, Testing, Monitoring | Job panjang, trigger, resume, quota |
| `GAS_FAMILY_ARCHITECTURE_DATA.txt` | Architecture, Database, PostgreSQL | Integrasi data, design |
| `GAS_FAMILY_WEB_UX.txt` | HtmlService + Product Design | Web app GAS |
| `GAS_FAMILY_WORKSPACE_INTEGRATIONS.txt` | Workspace Add-ons, Events/Chat | Workspace integration |
| `GAS_FAMILY_SECURITY_RELEASE.txt` | Security, Deployment, Compliance | OAuth, deployment, akses |
| `GAS_FAMILY_MIGRATION_DOCUMENTATION.txt` | AppSheet Migration + Documentation | Migrasi & runbook |
| `GAS_RELIABLE_JOBS.txt` | 3 starter `.gs` lengkap, byte-identical | Review/staging Reliable Jobs |
| `GEMINI_GEM_INSTRUCTIONS.txt` | Instruksi konfigurasi Gem | Tempel ke Instructions Gem |
| `MANIFEST.json` | 16 source SHA-256, 6 family & file hashes | Integrity audit lokal |

**Catatan penting:** keenam family memuat seluruh teks 16 `SKILL.md` tanpa perubahan, tetapi tautan relatif ke resource lain dalam repository *tidak otomatis tersedia* hanya karena keluarga tersebut diunggah. Untuk contoh kode Reliable Jobs, gunakan file tersendiri yang sudah dibundel. Ini bukan snapshot semua lampiran/referensi internal source tree.

## 3. Cara pakai — satu chat biasa

1. Jalankan `python tools/build_gemini_context.py` (satu kali untuk menghasilkan output) atau buka paket yang telah disediakan.
2. Untuk permintaan ringan, unggah **`GEMINI_GAS_CONTEXT.txt`** saja; untuk debugging serius tambahkan hanya `GAS_FAMILY_*.txt` relevan.
3. Contoh prompt: *"Gunakan GAS Engineering Playbook. Audit script saya yang gagal setelah 6 menit dan buat resume idempotent tanpa merusak data."*
4. Unggah skrip/log *yang sudah dibersihkan dari rahasia*. Untuk kode starter, tambah `GAS_RELIABLE_JOBS.txt`.
5. Jika unggah satu ZIP, pastikan UI Gemini mendukungnya; ZIP ini memiliki tepat 10 file, tetapi **belum diuji melalui akun Gemini nyata**.

## 4. Cara pakai — Gem reusable

1. Buka Gemini Apps → Gems → buat Gem.
2. Nama contoh: **GAS Engineering Reviewer**.
3. Tempel seluruh isi `GEMINI_GEM_INSTRUCTIONS.txt` pada instruksi Gem.
4. Di Knowledge, tambahkan `GEMINI_GAS_CONTEXT.txt` serta paling relevan family menurut pekerjaan Anda; untuk job panjang, tambah `GAS_RELIABLE_JOBS.txt`.
5. Simpan Gem; uji dengan pertanyaan spesifik dan tinjau apakah ia merujuk file yang benar. **Pembuatan/pengujian Gem belum dilakukan di akun pengguna**.

## 5. Cara pakai — Gemini CLI Agent Skills (opsional)

```bash
python tools/gas_skill_packager.py
python tools/build_gas_v2.py
python tools/verify_gas_v2.py
# Perintah CLI berikut hanya di komputer tempat Gemini CLI telah terpasang:
gemini skills install ./dist/gas-engineering-v2.0.0/gas-engineering.skill --scope workspace
# Jalankan `gemini`, kemudian `/skills list` atau `/skills reload`.
```

Gemini CLI dapat juga menemukan folder `<workspace>/.gemini/skills/gas-engineering/SKILL.md`. Struktur ini **berbeda** dari ZIP konteks yang ditujukan bagi Gemini Apps. Ikuti izin aktivasi yang diminta host dan verifikasi instalasi secara nyata; tidak ada klaim live di checkpoint ini.

## 6. Quality gates & keterbatasan

- Builder `tools/build_gemini_context.py`: ZIP deterministik, persis 10 anggota, input canonical 16/16 + mapping 6/6, source SHA-256, manifest SHA-256, ZIP CRC.
- `tools/test_gemini_context.py`: test coverage, helper fail-closed, tampering, ZIP extraction/safety, source fidelity, starter `.gs` identity.
- CI membangun dan memverifikasi paket tetapi **tidak mengakses akun Gemini**, tidak membuat Gem, dan tidak men-deploy GAS.
- Status `LIVE_GEMINI_APPS=NOT_RUN`, `LIVE_GEMINI_CLI=NOT_RUN`, `LIVE_GAS_STAGING=NOT_RUN`.
- File pengguna dapat memiliki data sensitif: jangan unggah token OAuth, `.clasprc.json`, konfigurasi rahasia, atau data produksi mentah.
- Validasi output AI secara manual sebelum melakukan perubahan ke GAS production.

## 7. Artefak pengembangan dan release policy

Output: `dist/gemini-v2.1-cp8/` (termasuk ZIP Gemini, file `.txt` terpisah, `MANIFEST.json`). `dist/` tetap `.gitignore`, sehingga tidak menyebabkan Git Windows long-path staging. Tidak ada tag, GitHub Release, atau perubahan `releases/v2.0.0/`.
