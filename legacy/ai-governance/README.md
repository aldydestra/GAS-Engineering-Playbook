# Legacy AI / Agent Governance Track

Frozen at repository v1.35.6.

This directory records the optional AI-agent packaging/governance work developed during v1.24–v1.35.6. It is **not part of the active GAS roadmap or default CI** as of v1.36.0.

The canonical project objective is Google Apps Script / Google Workspace engineering knowledge. Historical agent packaging, host lifecycle, v2 promotion, burn-in, signed-attestation, and release-closure tooling may remain in the repository for reference, but new releases do not treat those controls as product blockers.

The original GitHub workflows are stored under `legacy/ai-governance/workflows/` so they do not run automatically.
